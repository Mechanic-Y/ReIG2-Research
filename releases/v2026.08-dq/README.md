**Status:** release candidate / Zenodo preparation package  
**Prepared:** 2026-08-16

This directory records the public release package for the August 2026 ReIG-DQ update.

## Release intent

This release does **not** publish every post-March 2026 artifact. It publishes the minimum stable set needed to make the ReIG-DQ update understandable, citable, and auditable:

1. ReIG-DQ Japanese manuscript;
2. ReIG-DQ English manuscript;
3. ReIG2/twinRIG July 2026 revised integrated framework;
4. Three-Rationality Hierarchy Japanese paper;
5. Three-Rationality Hierarchy English paper.

B2OL, IMP-Ops, deployment dynamics, and ACFM are indexed as related or experimental layers, but their PDFs are intentionally kept out of this release package unless a later dedicated release is prepared.

## Files in this directory

- `MANIFEST_v2026.08-dq.md` — human-readable release manifest.
- `SHA256SUMS.txt` — checksum ledger for the five public release assets.
- `release_assets/README.md` — asset placement note.

## Asset policy

The five PDFs should be attached to the GitHub Release and Zenodo record as release assets. The repository stores the release notes, manifest, and hash ledger so that the public package can be verified after upload.
