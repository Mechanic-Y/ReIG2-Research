# ReIG-DQ audit layer

This directory records the audit-facing structure for ReIG-DQ.

The current `v2026.08-dq` release candidate uses a minimal public audit package:

- release manifest;
- SHA256 checksum ledger;
- bilingual manuscript status notes;
- Zenodo release notes;
- repository update inventory.

Future additions may include identity bridge files, freeze logs, source ledgers, and structural audit scripts.
