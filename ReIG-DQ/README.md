# ReIG-DQ

**ReIG-DQ** is the publication and verification layer for the August 2026 ReIG release package.

It is not a replacement for ReIG2, ReIG3, or RIF. It provides the release architecture around them:

- frozen manuscript identity;
- bilingual publication state;
- audit and verification notes;
- hash ledgers;
- GitHub / Zenodo release coordination;
- separation between core theory, applications, experiments, and adjacent mathematics.

## Current public manuscripts

- Japanese: `ReIG_DQ_Japanese_Manuscript_v1.1_BIBLIOGRAPHY_FROZEN.pdf`
- English: `ReIG_DQ_English_Manuscript_v1.0_SYNCHRONIZED_FROZEN.pdf`

The canonical release package is recorded under `../releases/v2026.08-dq/`.

## Directory guide

- `papers/v1_2026-08/ja/` — Japanese manuscript notes.
- `papers/v1_2026-08/en/` — English manuscript notes.
- `audit/` — freeze, provenance, and verification structure.
- `docs/` — future supporting documentation.
